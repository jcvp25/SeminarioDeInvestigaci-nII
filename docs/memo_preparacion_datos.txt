CREATININA BASAL (creatinina_mg_dl_basal):
  ERC-0047: valor original 0.08 → valor corregido 0.84
    Justificación: Error de punto decimal; el valor real es 0.84 mg/dL según log.
  ERC-0271: valor original 142.0 → valor corregido 1.61
    Justificación: Confusión de unidades (µmol/L → mg/dL). 142.0 / 88.4 = 1.61 mg/dL.
  ERC-0183: valor original 18.5 → conservado
    Justificación: Valor extremo pero posible en ERC G4 severa. Marcado para sensibilidad.

PESO BASAL (peso_kg_basal):
  ERC-0112: valor original 8.5 → NA_real_
    Justificación: Imposible para un adulto, error de digitación irrecuperable.
  ERC-0294: valor original 198.0 → conservado
    Justificación: Posible caso de obesidad mórbida.
